# Tic-Tac-Toe Game 

A responsive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features

- 2 Player Mode
- Play Against Computer
- Easy, Medium & Hard difficulty
- Player name customization
- Score tracking
- Winner animation
- Winner popup
- Sound effects
- Dark/Light mode
- Responsive design for mobile and desktop

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Web Audio API
